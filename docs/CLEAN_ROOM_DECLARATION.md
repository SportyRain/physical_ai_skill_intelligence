# Clean-room declaration

This v0.1.0 source tree was generated as a fresh project base.

- Previous temporary `physical_ai_skill_intelligence` work is not authoritative.

  normalized datasets, temporary configs, or prior verification reports.

- Future evidence importers must preserve source repository, commit, path,
  record identity, schema version, and content hash when available.
